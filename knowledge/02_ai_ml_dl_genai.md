# AI, machine learning, deep learning and generative AI (IBM Technology)
Source: https://www.youtube.com/watch?v=qYNweeDHiyU

## Key points
- The fields are **nested** (a Venn diagram): AI ⊃ machine learning ⊃ deep learning ⊃ generative AI / foundation models.
- **Artificial intelligence**: using computers to simulate or exceed human intelligence, i.e. the ability to learn, infer and reason. Early AI used languages like Lisp and Prolog; **expert systems** (1980s–90s) were hand-written rules, with no learning from data.
- **Machine learning**: the machine learns patterns from data instead of being explicitly programmed. It is good at **prediction** (more training data means more confident predictions) and at **spotting outliers/anomalies**, for example in cybersecurity or fraud detection. It became popular in the 2010s.
- **Deep learning**: ML using **neural networks** with many layers (that's what "deep" means), loosely mimicking the brain. Because of the many layers it is hard to explain why a given output was produced, which links to explainability.
- **Generative AI** builds on **foundation models** such as LLMs. An LLM is like a very powerful autocomplete: it predicts what comes next, but it can produce sentences, paragraphs and whole documents. Other foundation models handle audio, video and images. These enable both useful applications (chatbots, summaries, restoring a lost voice) and abuse (**deepfakes**).
- "Is generative AI really generative, or does it only recombine?" The speaker's analogy: every musical note already exists, yet new songs are still composed, so recombination can still create new content.
- Adoption was slow for decades, picked up with ML and deep learning, and exploded with foundation models and generative AI.

## Things an interviewer can ask
- Place AI, ML, deep learning and generative AI relative to each other.
- How does an expert system differ from machine learning?
- Why is deep learning hard to explain? Give a business use of anomaly detection.
